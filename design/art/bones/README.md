# 캐릭터 뼈대(본) — 일반병 10 · 장수 20 · 적 9

`tools/make_bones.py`가 만든다. 이 뼈대 위에 캐릭터를 그리고(Codex), 스프라이트(PixelLab)를 뽑는다.
뼈대 자세와 크기는 게임 임시 그림(`tools/draw_art.py`)과 **같은 값**에서 나온다. 한쪽을 바꾸면 다른 쪽도 같이 바뀐다.

| 파일 | 내용 |
|---|---|
| `soldier_<id>.png` | 일반병 10종: 창병 spear, 극병 halberd, 방패병 shield, 도부수 axe, 궁병 archer, 노병 crossbow, 경기병 rider, 중기병 heavy, 화공술사 fire, 뇌공술사 thunder |
| `hero_<id>.png` | 장수 20명. 자기 병종 뼈대 + 고유 무기 + 표식(분홍) |
| `enemy_<id>.png` | 황건적 9종 (잡병 · 검병 · 창병 · 궁병 · 방패병 · 기병 · 요술사 · 괴력 장수 · 장각) |
| `_all.png` | 한눈에 보기 |
| `bones.json` | 관절 좌표 (6자세). 뼈대 단위, 게임 픽셀 = 단위 × 0.24 |

## 1. 크기 기준 (꼭 지킬 것)

| 항목 | 일반 | 기병 |
|---|---|---|
| **그림 칸 (원본 픽셀)** | **64 × 64** | **96 × 80** |
| **발 기준점** | 칸 아래 가운데 (32, 63) | 칸 아래 가운데 (48, 79) = 말 몸 가운데 |
| 머리 지름 | 15 px | 15 px |
| 키 (머리끝~발) | 45 px | 사람 45 px, 말 위에 앉음 |
| 몸 (목~엉덩이) | 13 px | 13 px |
| 다리 (엉덩이~발) | 16 px | 16 px (말 옆구리를 따라 굽힘) |
| 팔 (어깨~손) | 11 px | 11 px |
| 말 몸 길이 | - | 경기병 27 px, 중기병 30 px |
| 무기 길이 | 시트마다 표에 적음 (창 38 · 기병창 46 · 극 41 · 활 26 · 검 19 px …) | |
| 화면 표시 (전투) | 64 → 113 px (×1.76) | 80 → 139 px (×1.74) |

- 2.5등신: 머리 지름이 키의 약 1/3.
- **발은 반드시 칸의 맨 아래 줄**에 닿는다. 게임이 그 점을 땅에 놓는다. 위·옆 빈 곳은 무기와 깃털 자리다.
- 모든 프레임은 같은 칸 크기, 같은 발 위치. 프레임마다 칸을 자르지 않는다.
- 크게 그려도 된다: 4배(256 × 256 / 384 × 320)로 그린 뒤 최근접 축소. 비율은 위 표 그대로.

## 2. 자세 (시트마다 6칸)

| 자세 | 게임 프레임 | 설명 |
|---|---|---|
| 대기 | idle 4장 (6 fps) | 무기를 세워 든다. 2·3장째 상체 1px 내려감(숨쉬기) |
| 달리기 1 · 2 | run 6장 (10 fps) | 두 자세 사이를 오간다 (다리 교차, 팔 반대로) |
| 공격 | attack 5장 (10 fps) | 뒤로 당김 → 찌름(시트 자세) → 유지 → 돌아옴 |
| 맞음 | (예정) hit | 상체가 뒤로 젖혀짐 |
| 쓰러짐 | (예정) die | 뒤로 눕는다. 무기는 떨어뜨림 |

## 3. 읽는 법

- 모두 **오른쪽을 본다.** 코 삼각형 = 보는 방향, 흰 점 = 눈, 흰 선 = 입.
- 칸 16 = 뼈대 16단위 = 게임 약 4px. 아래 회색 선 = 땅.
- 색: 머리 빨강, 몸 노랑, 앞팔·앞다리 밝게, 뒷팔·뒷다리 어둡게(몸 뒤에 그린다).
- 손 = 흰 원, 안의 검은 선 = 쥐는 방향. 발 = 흰 발끝(앞쪽).
- 무기 = 흰 자루 + 주황 날. 길이와 쥐는 손을 지킨다.
- 말 = 보라. 말 머리도 오른쪽.
- 분홍 = 장수·적 표식 (관우 긴 수염·두건, 하후돈 왼눈 안대, 여포 꿩깃 2개, 황충 흰 수염, 황건적 노란 두건 등).
- 시트 오른쪽 아래: 지금 게임에 들어간 **임시 그림**을 3배로, 칸(노란 테)과 발 기준점(빨간 십자)과 함께 보여 준다.

## 4. 요청 틀 (Codex / PixelLab)

```
weapon exactly where the skeleton shows them. Weapon: <무기, 길이 px>. Marks: <표식>.
Bright daytime palette, 1 px dark outline, transparent background. Poses: idle, run x2, attack, hit, die.
```

## 5. 주의

- 생김새는 우리가 새로 정한다. 다른 게임의 캐릭터를 따라 그리지 않는다.
