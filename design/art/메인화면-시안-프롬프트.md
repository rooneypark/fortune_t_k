## 0. 공통 설정 (두 프롬프트가 공유하는 게임 정보)

### 게임 한 줄
점괘(占卦)로 병사를 모으고 가끔 터지는 삼국지 장수에게 병사를 먹여 키우며, 성벽 앞 들판에 진을 쳐 황건적을 막는 **2D 픽셀 삼국지 로그라이트 오토 디펜스**. 제목은 **운빨삼국**(운에 기대는 삼국지라는 장난스러운 이름).

### 분위기 키워드
- 동양 점술 + 난세 전쟁 + 약간의 도박 긴장감 + 귀엽고 경쾌한 픽셀
- "대길(大吉)이 뜰까, 대흉(大凶)이 뜰까" 두근거리는 뽑기 감성
- 무겁고 사실적인 전쟁화가 아니라, **작고 귀여운 픽셀 인물들이 큰 싸움을 벌이는** 느낌

### 아트 스타일
- **2D 픽셀아트**, 기준 해상도 480×270 픽셀 캔버스를 정수배로 확대(4.5배 = 2160×1215 근처). 픽셀 가장자리가 또렷해야 한다 (흐림·안티에일리어싱 금지).
- 인물: **2~2.5등신 치비 비율의 옆모습**, 인물 키 약 32~48픽셀. 굵은 어두운 외곽선(먹색), 2~3단계 음영.
- 배경: 픽셀이지만 깊이감 있는 층(먼 산, 성벽, 들판). 동양 수묵 담채 느낌의 색 번짐을 픽셀 디더링으로 표현.
- UI: 픽셀 아트로 그린 **죽간(대나무 쪽 묶음)·한지·옥·부적·향로·점대 통** 모티프. 모서리는 각진 픽셀 장식, 9-slice로 늘릴 수 있는 형태.

### 색 팔레트 (역할 포함)

### 등장시킬 캐릭터 (메인화면 장식용)
- **군주 유비** — 녹색 도포, 학자 관모, 쌍고검. 성루 위에서 들판을 내려다보는 모습. 화면의 중심 인물.
- **관우** — 붉은 얼굴, 긴 검은 수염, 녹색 두건과 갑옷, 청룡언월도, 붉은 말. 대표 장수.
- **장비** — 검은 덥수룩한 수염, 붉은 머리띠, 장팔사모.
- **여포** — 꿩 깃털 두 가닥이 솟은 금관, 방천화극, 붉은 말. 위협적인 라이벌 느낌.
- **주유** — 흰 도포, 깃털 부채. 화공 이미지.
- **병사들** — 창병·방패병·궁병·기병이 작게 줄지어 서 있다 (장수보다 작고 단순).
- **적 황건적** — 누런 두건을 쓴 무리가 멀리 지평선에서 몰려온다. 거대한 보스 **장각**(금관, 노란 도포, 구절장)이 하늘에 희미한 실루엣으로.
- 각 장수 등 뒤에 **세력 색 깃발**(작은 사각 깃발).
- 인물 디자인은 **우리 오리지널**이어야 한다. 코에이 삼국지·진삼국무쌍 등 기존 게임의 초상·디자인을 따라 하지 않는다.

### 게임만의 상징 (화면에 꼭 넣을 것)
- **점괘 제단**: 향로에서 피어오르는 향 연기, 점대 통(산가지가 꽂힌 원통), 바닥의 팔괘(八卦) 문양 원판. 메인 버튼 근처.
- **길흉 도장**: 붉은 사각 인장에 한자 `大吉`, `吉`, `凶`, `大凶`. 장식으로 비스듬히 찍힌 느낌.
- **효(爻) 6줄**: 점괘 카드 뒷면 무늬 (긴 막대 / 끊긴 막대 6줄).
- **운(運) 게이지**: 칸이 10개인 붉은 구슬 줄 — 가득 차면 금빛으로 변함.

### 화면 사양 — 모바일 가로
- 기준 비율 **19.5:9** (예: 2340×1080). 16:9(1920×1080) 기기에서는 좌우가 잘려도 되게, 핵심 UI는 가운데 **16:9 안전 영역** 안에 둔다.
- 좌우 끝 **노치/펀치홀 안전 여백 각 88px**(2340 기준), 아래 **홈 제스처 여백 40px**.
- **엄지 영역:** 자주 누르는 버튼(출정)은 오른쪽 아래, 두 번째로 자주 쓰는 것(점괘 미리보기·도감)은 왼쪽 아래. 상단은 정보 표시 위주.
- 터치 버튼 최소 **48×48dp**, 글자 최소 **12pt**(화면 높이 1080 기준 약 32px 이상).

### 넣지 말 것
- 기존 게임(코에이 삼국지, 진삼국무쌍, 슬롯바운드, 기타 모바일 삼국지)의 로고·초상·UI 배치를 닮게 하지 말 것
- 사실적인 3D 렌더, 매끈한 벡터 일러스트, 흐릿한 업스케일 픽셀
- 서양 판타지 요소(엘프, 드래곤 기사, 마법진 룬 문자)

- 화면을 가득 채운 글자, 작은 글씨

## B. 코드 시안 프롬프트 (클로드용)

```
너는 모바일 게임 UI 디자이너 겸 프론트엔드 개발자야. 아래 게임의 "메인화면(로비)" 시안을 HTML 한 파일(인라인 CSS·SVG·JS)로 만들어 줘. 외부 이미지 없이, 그림은 전부 CSS 도형·SVG·박스 그림자 픽셀 기법으로 그린다.

[게임]
- 제목: 운빨삼국 (FORTUNE OF THREE KINGDOMS)
- 장르: 2D 픽셀 삼국지 로그라이트 오토 디펜스. 점괘(1·2·3괘)로 병사를 모으고 드물게 장수가 나온다. 성벽 앞 들판에 진을 쳐 황건적을 막는다.
- 분위기: 동양 점술 + 난세 전쟁 + 뽑기의 두근거림, 작고 귀여운 픽셀 인물.

[화면 사양]
- 모바일 가로. 기준 캔버스 2340×1080(19.5:9)을 CSS 변수로 두고, 브라우저 창에 비율 유지하며 맞춘다(letterbox).
- 좌우 노치 안전 여백 88px, 아래 40px. 핵심 UI는 가운데 16:9(1920×1080) 안전 영역 안에. 안전 영역 경계를 토글로 보이게(키 S).
- 버튼 최소 높이 120px(1080 기준), 글자 최소 32px.
- 폰트: 제목은 굵은 붓글씨 느낌(가능하면 Google Fonts의 한국어 붓글씨 계열, 없으면 시스템 굵은 글꼴 + 픽셀 그림자), 본문은 또렷한 고딕.
- image-rendering: pixelated 로 픽셀 느낌 유지.

[색 토큰] (CSS 변수로)
--ink #1A120B, --paper #EFE2C2, --bamboo #B88E52, --vermilion #C0392B, --gold #E8B93A, --jade #7A3A9A, --jade-light #C88AF0, --shu #3F9E4D, --wei #3B6FD6, --wu #C8402F, --qun #D6A83A, --yellow-turban #E8C32A

- 왼쪽 위: 플레이어 정보(원형 옥 테두리 초상, 이름 「유비」, 명성 Lv12 바)
- 위 오른쪽: 재화 바 — 명성 12,450 / 천명석 38, 각각 + 버튼. 그 오른쪽에 부채(설정)·죽간 편지(우편, 빨간 점 알림)·북(공지) 아이콘
```
