# 운빨삼국 — MVP 장수 목록 (v0.1)

- **v0.5:** 장수는 점괘에서 희귀하게 나온다(카드당 약 8~12%). 영입 비용 ★1 3금 ~ ★5 10금, 지휘 반경으로 같은 병종 병사를 강화한다 — [병사와 장수](병사와-장수.md).
- 24명 = 4세력 × 6명. 등급 분포: ★1 4명, ★2 6명, ★3 6명, ★4 4명, ★5 4명.
- 인물 선정은 참고 리소스(참고 게임)에 **임시 리소스가 있는 장수**를 우선했다. 임시 리소스 ID는 (삭제된 문서) 참고.
- 기술·각인·전직·천명 이름은 모두 운빨삼국 자체 설정이다. 참고 게임의 고유 명칭(예: "용신 조운")은 쓰지 않는다.
- 수치는 GDD §5.6 등급 기본값을 따르고, 여기서는 역할만 정한다. `[튜닝]`

## 2. 장수 상세

표기: 저지 = 동시에 막는 적 수. 전직은 2성 1차 분기(A/B)만 적고, 3성 2차 분기는 프로토타입 2에서 정한다.

| 관평 | ★1 | 보병 | 3 | **부자진**: 3초간 방어 +50%, 관우가 있으면 관우 기력 +20 | 관우와 같은 로에 있으면 공격 +15% | 호위장(저지 +1) / 선봉(공격형) |

## 4. 고사 시너지 (MVP 기준으로 조정)
| 이름 | 조건 | 효과 | 비고 |
|---|---|---|---|
| 도원결의 | **군주 유비** + 관우 + 장비 | 셋 중 하나가 쓰러져도 5초간 불사 | 유비는 장수가 아니라 군주 |
| 오호대장군 | 관우·장비·조운·황충 중 3 / 4 (+마초 이후 추가) | 공격 +20% / +50% | |
| 적벽 | 주유 + 황개 + 제갈량 | 웨이브 시작 시 3로 화공 1회 | |
| 오자양장 | 장료 + 장합 (+서황·악진·우금 이후) | 기병 돌격 피해 +30% | 신규 |
| 천하무쌍 | 여포 단독 (다른 군웅 없음) | 여포 능력치 2배 | 각인과 동일 |
| 남만왕 | 맹획 + 화만 | 맹수 소환 2마리 | 신규 |
| 와룡봉추 | 제갈량 + 방통 | 계책 2회 연속 | MVP 제외 (방통 없음) |
