# 운빨삼국 — 화면 흐름과 화면 설계 (v0.1)

> **이력 문서 (2026-11-21).** 정본은 `design/gdd/운빨삼국-GDD_v5.md`. 이 문서와 다르면 v5를 따른다.

- 기준 해상도: **480×270** 픽셀 캔버스, 정수배 확대 (1920×1080 = ×4). 모든 좌표는 480×270 기준.
- 입력: 마우스 우선 + 단축키. 터치는 고려만 하고 MVP 범위 밖.
- 원칙
  1. **준비 화면 하나에서 모든 결정을 한다.** 점괘, 영입, 흡수, 배치, 레벨업이 화면 전환 없이 이어진다.
  2. **확률과 수치를 숨기지 않는다.** 천기 조작의 재미는 계산할 수 있어야 생긴다 (GDD §1.8).
  3. 길흉은 **색 + 글자**로 함께 표시한다 (색만으로 구분하지 않음).
  4. 연출은 1초 이내, 전부 스킵 가능. 천명만 2초.

## 1. 화면 흐름

```
타이틀 ─→ 군주 선택 ─→ ┌──────────── 런 루프 ────────────┐
  │                    │                                   │
  ├─ 도감              │  [사건] (30%) ─→ 준비 화면 ⇄ 점괘 팝업 / 장수 정보
  ├─ 해금(명성)        │                    │ 전투 시작        │
  └─ 설정              │              (시련 웨이브면 판돈 선택)  │
                       │                    ↓                   │
                       │                 전투 화면              │
                       │                    ↓                   │
                       │                 결산 화면              │
                       │   보스/시련/7웨이브 뒤 → 보상 선택 (비전·보물) │
                       └──────────── 다음 웨이브 ──────────────┘
                                  │ 성 0 또는 3장 클리어
                                  ↓
                         런 종료 (명성 정산) ─→ 타이틀
```

| 화면 | 들어오는 조건 | 나가는 곳 |
|---|---|---|
| 타이틀 | 실행 | 군주 선택, 도감, 해금, 설정, 이어하기 |
| 군주 선택 | 새 원정 | 준비 화면 (1웨이브) |
| 사건 | 웨이브 사이 30% | 준비 화면 |
| 준비 화면 | 매 웨이브 시작 | 점괘 팝업, 장수 정보, 시련 판돈, 전투 |
| 점괘 팝업 | 점괘 버튼 | 준비 화면 (천명이면 천명 컷인 거쳐서) |
| 시련 판돈 | 시련 웨이브에서 전투 시작 | 전투 |
| 전투 | 전투 시작 | 결산 |
| 결산 | 웨이브 종료 | 보상 선택 또는 다음 준비 화면, 런 종료 |
| 보상 선택 | 보스·시련 성공·7웨이브 뒤 | 준비 화면 |
| 런 종료 | 성 0 / 3장 클리어 | 타이틀 |

### 2.1 영역
| 영역 | 위치 (x, y, w, h) | 내용 |
|---|---|---|
| 상단 바 | 0, 0, 480, 16 | 장·웨이브(시련/보스 표시), 성, 금(다음 수입 예고), 향, 운 게이지, 주공 레벨·XP, 설정 |
| 시너지 목록 | 0, 16, 48, 180 | 발동 중인 세력·병종·고사, 단계 표시. 마우스 올리면 효과 설명 |
| 비전 | 시너지 아래 | 보유 비전 아이콘 최대 5개 |
| 성·군주 | 48, 16, 32, 180 | 군주 외형, 군령은 전투 중에만 활성 |
| 배치칸 | 80, 16, 160, 180 | 3로 × 4열, 칸 40×60 |
| 적 미리보기 | 240, 16, 240, 180 | 다음 웨이브의 로별 적 구성 (아이콘 + 수) |
| 대기석 | 0, 196, 480, 30 | 8칸. 출전 수 / 최대 출전 수 |
| 행동 바 | 0, 226, 480, 44 | 점괘 3종, 향 추가, 레벨업, 계책, 봉인 슬롯, 출전 |

### 2.2 조작
| 조작 | 결과 |
|---|---|
| 대기석 → 배치칸 드래그 | 배치. 출전 수 초과 시 칸이 붉게 표시, 놓을 수 없음 |
| 배치칸 ↔ 배치칸 드래그 | 자리 교환 |
| 장수 → 다른 장수 위로 드롭 | **흡수 확인 팝업** (먹이·대상, 얻는 경험치, 자질 전이 확률 표시) |
| 같은 장수 3명 보유 | 장수 위에 "결의" 아이콘 깜빡 → 클릭 시 합성 |
| 장수 클릭 | 장수 정보 패널 (§4) |
| 장수 → 행동 바의 판매 영역 드래그 | 판매 (환급 금액 미리 표시) |
| 운 게이지 마우스 올리기 | 현재 운, 만충 시 효과 |
| 향/금 부족 | 버튼 회색 + 부족한 자원 표시 |

### 2.3 단축키
`1` `2` `3` 점괘 · `F` 레벨업 · `Q` 향 추가 · `E` 선택 장수 판매 · `Space` 출전 · `Tab` 시너지 상세 · `Esc` 메뉴

## 3. 점괘 팝업

```
┌───────────────────────── 三才卦 · 향 1 소모 ─────────────────────────┐
│                                                                     │
│   ┌──────────┐      ┌──────────┐      ┌──────────┐                  │
│   │  [吉]    │      │  [平]    │      │ [大凶]   │  ← 괘상 도장      │
│   │  (일러스트)│~~~~~~│ (일러스트) │      │ (일러스트) │  ~~ 괘 맞춤 실    │
│   │ 조운 ★3  │      │ 관우 ★4  │      │ 화만 ★1  │                  │
│   │ 蜀 기병   │      │ 蜀 맹장·기병│      │ 群 궁병   │                  │
│   │ 자질: 신속 │      │ 자질: 철벽 │      │ 자질: 겁쟁이│                  │
│   │       ?  │      │       ?  │      │   혼란    │                  │
│   │ 영입 2金  │      │ 영입 5金  │      │ 영입 0金  │                  │
│   │ (3→2)    │      │          │      │ 운 +3     │                  │
│   └──────────┘      └──────────┘      └──────────┘                  │
│   동문(同門) 2/3 — 같은 세력 1장 더면 자질 +1                            │
│                                                                     │
│      [ 영입 ]  (카드 선택 후)        [ 봉인 ]        [ 포기 ]          │
└─────────────────────────────────────────────────────────────────────┘
```

| 요소 | 규칙 |
|---|---|
| 카드 공개 | 점대 통 흔들기 → 효(爻) 6줄 → 카드 뒤집힘. 카드당 0.25초, 클릭으로 즉시 공개 |
| 괘상 도장 | 대길 금 / 길 녹 / 평 회 / 흉 적 / 대흉 흑적 + **한자 글자** |
| 영입 비용 | 괘상 반영 가격, 원래 가격은 작게 취소선 |
| 자질 | 확정된 자질만 표시, 아직 안 굴린 칸은 `?` (영입 순간 굴림 연출) |
| 괘 맞춤 | 겹치는 카드끼리 붉은 실로 연결 + 맞춤 이름. 미완성 맞춤도 "2/3"으로 표시 |
| 인연 보장 (3괘) | 보장 카드 모서리에 매듭 아이콘 |
| 1괘 | 카드 1장, 버튼은 영입 / 봉인 / 포기 |
| 대기석 가득 참 | 영입 버튼 대신 "대기석 가득 — 판매 또는 흡수 먼저" |
| 운 | 흉·대흉 카드가 뒤집힐 때 운 게이지로 빛이 날아감 |

### 3.1 천명 컷인 (잭팟)
1. 세 카드가 한가운데로 모여 하나로 겹침 (0.3초)
2. 화면 전체 금빛, 하늘이 열리고 용이 가로지름 (1.2초)
3. 천명 장수 등장 + 이름 붓글씨 (0.5초)
4. 클릭 → 대기석으로 들어감. 대기석이 차 있어도 **임시 9번째 칸**에 들어간다.

## 4. 장수 정보 패널 (우측 슬라이드, 160×250)

```
┌────────────────────┐
│ (일러스트)  관우 ★4 ●●○ │ ← 성급 (2성)
│ 蜀 · 맹장 · 기병       │
│ 체력 1710  공격 153    │
│ 방어 63    공속 0.85   │
│ 저지 2                │
├────────────────────┤
│ 무장 기술: 청룡언월      │
│  자기 로 전체 일자 베기   │
│ 각인: 처치마다 공격 +3%  │
├────────────────────┤
│ 자질  신속 ▲  철벽      │
│      (빈칸)            │
│ 흡수 ▮▮▮▯▯ 2/3단계      │
├────────────────────┤
│ 전직: 2성 도달 → 선택    │
```

- 전직 가능하면 패널이 자동으로 열리고 두 경로를 나란히 비교.

## 5. 시련 판돈 (팝업)
```
┌─────────── 시련: 황건 결사대 ───────────┐
│  [사양]       [小]              [大]      │
│  일반 전투    적 +30%           적 +60% · 안개 │
│              새어 나감 ≤5       새어 나감 ≤3   │
│              보상 ×2           비전 1 + 금 ×3  │

```
- **예상 성 피해**를 반드시 보여 준다. 위험을 알고 거는 도박이어야 한다.

## 6. 전투 화면

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ W3/10 │ 城 82 │ 金 23 │ 남은 적 14/17 │ 새어 나감 1 (≤5 성공) │ ⏸ │ ▶▶       │
├──────────────────────────────────────────────────────────────────────────────┤
│ [성]│ 장비 │     │ 황충 │     │ ←검병 ←검병        ←궁병                        │
│ 유비├─────┼─────┼─────┼─────┤                                                │
│     │ 관우 │ 조운 │     │     │ ←기병 ←기병                                    │
│     ├─────┼─────┼─────┼─────┤                                                │
│     │     │     │     │     │ ←방패 ←검병                                    │
├──────────────────────────────────────────────────────────────────────────────┤
│ 군령 [인덕: 전군 치유] 1회   │ 계책 [연환계] [   ]   │ 시너지 발동 로그        │
└──────────────────────────────────────────────────────────────────────────────┘
```
- 장수 머리 위: 체력 바 + 기력 바. 기력 100이면 자동 발동 (수동 발동 없음).
- 적이 성에 닿으면 성이 흔들리고 피해 숫자가 성 위로 튐.
- 계책 사용: 버튼 클릭 → 대상(로 또는 적) 선택. 사용 중 시간 0.3배 느려짐.
- 보스: 상단에 보스 체력 바, 패턴 예고는 바닥에 붉은 표시 1.5초.

## 8. 보상 선택 (비전·보물)
- 카드 3장 중 1장. 비전은 보유 비전과의 **연쇄 효과를 미리 표시** (예: "흉중길 + 천문 → 흉 1회당 금 +1, 운 만충 7").
- 1회 재추첨 무료 (명성 해금으로 횟수 증가).

## 9. 사건 화면
- 일러스트 1장 + 상황 글 2~3줄 + 선택지 2~3개. 선택지마다 대가와 보상을 숫자로 표시.

## 10. 런 밖 화면
| 화면 | 내용 |
|---|---|
| 타이틀 | 새 원정, 이어하기(웨이브 단위 저장), 도감, 해금, 설정 |
| 군주 선택 | 군주 카드 3장(+잠김), 패시브·군령 설명, 추천 세력 표시 |
| 도감 | 장수(발견한 자질·전직 경로 기록), 적, 천명 형태(실루엣으로 숨김) |
| 해금 | 명성으로 군주·장수·보물·비전 해금 |
| 런 종료 | 도달 웨이브, 최다 처치 장수, 천명 횟수, 운 최대치, 획득 명성 |
| 설정 | 배속 기본값, 연출 스킵, 화면 흔들림 끄기, 음량, 해상도 배율 |

## 11. 프로토타입 1에 필요한 최소 화면
준비 화면, 점괘 팝업, 전투 화면, 결산 화면, 런 종료. 나머지(사건, 시련 판돈, 보상 선택, 도감, 해금)는 프로토타입 2에서 추가.
