# 운빨삼국 — 자질 · 비전 · 보물 · 계책 목록 (v0.1)

GDD §3.1(자질), §6(보물·비전·계책)의 전체 목록. 수치는 모두 `[튜닝]`.

## 1. 자질(資質) 30종

### 1.1 규칙
| 항목 | 값 |
|---|---|
| 영입 시 개수 | ★1~2: 1개, ★3~4: 2개, ★5: 3개 |
| 희귀도 | 일반 60% / 희귀 30% / 전설 10% |
| 괘상 영향 | 대길: 희귀 이상 1개 추가 · 흉: 나쁜 자질 1개 추가 · 대흉: 나쁜 자질 2개 추가 |
| 강화 (흡수) | I → II (수치 ×1.5) → III (수치 ×2) |
| 중복 | 같은 자질은 하나만. 다시 나오면 그 자질이 한 단계 강화 |
| 제약 | "근접 전용", "원거리 전용" 자질은 맞지 않는 장수에게 나오지 않음 (다시 굴림) |
| 최대 개수 | 좋은 자질 5개 (흡수로 추가) |
| 전이 | 흡수할 때 먹이의 좋은 자질 30% 확률로 전이. 나쁜 자질은 전이 없이 사라짐 |

### 1.3 나쁜 자질 8종 (흉·대흉에서만)
| 자질 | 효과 | 해소 |
|---|---|---|
| 겁쟁이 | 체력 30% 이하에서 공격 중지, 저지 해제 | 흡수 먹이로 쓰면 사라짐 (공통) |
| 혼란 | 웨이브 시작 3초간 행동 불가 | |
| 탐욕 | 출전 중이면 웨이브마다 금 -1 | |
| 불화 | 세력 시너지 인원에 포함되지 않음 | |
| 둔중 | 공속 -20% | |
| 허약 | 체력 -20% | |
| 오만 | 저지 -1 (근접), 사거리 -1 (원거리) | |
| 불운 | 출전 중이면 점괘 흉 확률 +3%p | 비전 "흉중길"과 묶으면 오히려 이득 |

- 비전 "명경지수"가 있으면 나쁜 자질 1개가 무효가 된다.
- 설계 의도: 나쁜 자질은 **"싸게 샀으니 먹이로 쓰거나, 감수하고 쓴다"**는 선택이 되게 한다. 장수를 완전히 못 쓰게 만드는 자질은 넣지 않는다.

## 2. 비전(秘傳) 20종 — 런 규칙을 바꾸는 코어

### 2.1 규칙
- 최대 8개 (v0.5). 9번째를 얻으면 하나를 버려야 한다.
- 획득: 보스 처치(3중 택1), 대(大) 시련 성공, 일부 사건.
- 희귀도: 일반 / 희귀 / 전설. 전설은 보스 보상에서만.
- 태그는 빌드 방향. 보상 선택 화면에 보유 비전과 겹치는 태그를 강조한다.

### 2.2 목록
| 비전 | 희귀도 | 태그 | 효과 |
|---|---|---|---|
| 흉중길(凶中吉) | 일반 | 운 · 경제 | 흉이 나올 때마다 금 +1 (대흉은 +3) |
| 천문(天文) | 희귀 | 운 | 운 게이지 최대치 10 → 7 |
| 하늘의 뜻 | 전설 | 운 · 천명 | 천명 확률 ×3, 대신 대흉 확률 +5%p |
| 쌍룡(雙龍) | 희귀 | 점괘 | 괘 맞춤 "쌍" 확률 ×2 |
| 역술가 | 일반 | 점괘 · 경제 | 2괘·3괘 점 비용 -1 |
| 백일향(百日香) | 희귀 | 점괘 | 웨이브마다 향 +1 |
| 군량 비축 | 일반 | 경제 | 웨이브 시작 시 남은 향 1개당 금 +1 (전투 전 정산) |
| 거상(巨商) | 일반 | 경제 | 이자 상한 +3 |
| 삼고초려 | 희귀 | 점괘 | 같은 장수의 3번째 카드는 영입 비용 0 |
| 제명부(除名簿) | 희귀 | 점괘 | 획득 즉시 장수 2종을 런 풀에서 제거 |
| 식객 3천 | 희귀 | 흡수 | 흡수 경험치 +50%, 자질 전이 30% → 50% |
| 명경지수 | 일반 | 흡수 | 모든 장수의 나쁜 자질 1개 무효 |
| 칠진칠출 | 희귀 | 방어 | 보호막이 깨질 때 주변 적에게 피해 |

| 배수진 | 희귀 | 방어 · 공격 | 성 50 이하일 때 아군 전원 공격 +30% |
| 일기당천 | 희귀 | 공격 | 최대 출전 수보다 1명 적을 때마다 아군 공격 +10% |
| 화우(火雨) | 희귀 | 화공 | 화상 피해 +50%, 화상 중 죽은 적이 주변에 화상 전파 |
| 철기(鐵騎) | 희귀 | 기병 | 기병 돌격 횟수 +1, 돌격 피해 +20% |
| 귀모(鬼謀) | 희귀 | 계책 | 계책 사용 시 아군 전원 기력 +30 |
| 천명의 그릇 | 전설 | 천명 | 천명 장수가 출전 중이면 아군 전원 능력치 +20% |

### 2.3 대표 빌드 (밸런스 점검용)
| 빌드 | 조합 | 노리는 것 | 위험 |
|---|---|---|---|
| **운빨 도박** | 흉중길 + 천문 + 하늘의 뜻 + 군주 동탁 | 1괘 연타 → 운 만충 → 3괘 천명 | 대흉 장수가 쌓여 전력 부족. **과도하게 강하면 하늘의 뜻 수치부터 조정** |
| 흡수 괴물 | 식객 3천 + 명경지수 + 삼고초려 | 장수 1~2명에게 자질 5개 III단계 | 단일 장수 의존, 로 하나가 뚫림 |
| 적벽 화공 | 화우 + 주유 + 황개 + 육손 | 3로 전체 화상 연쇄 | 방패병·보스에 약함 |
| 철기 돌파 | 철기 + 장료 + 조운 + 오자양장 | 웨이브 초반 돌격으로 정리 | 공성병 저지 부족 |
| 소수 정예 | 일기당천 + 여포(천하무쌍) | 출전 3~4명으로 버팀 | 로 3개를 다 막기 어려움 |

## 3. 보물(寶物) 16종

### 3.1 규칙
- **장수 보물**: 장수 1명에게 1개 장착. 판매·흡수하면 대기석으로 돌아온다.
- **성 보물**: 장착 없이 성에 둔다. 최대 3개.
- 획득: 7웨이브 뒤 보물 상점(3중 택1), 대길 영입 시 10% 확률, 사건.

|---|---|---|

| 청룡언월도 | 무장 기술 범위 +50% | 관우 |
| 방천화극 | 공격 +25%, 처치 시 주변에 50% 피해 | 여포 |
| 장팔사모 | 저지 +1, 저지 중인 적에게 피해 +20% | 장비 |
| 청강검 | 방어 30% 무시 | 조운 |
| 의천검 | 공격이 관통 (뒤의 적 1명 50%) | |

## 4. 계책(計策) 12종 — 1회성

### 4.1 규칙
- 최대 2장 보유 (책사 시너지 4단계에서 3장).
- 사용 시점: **준비** = 준비 단계에서만, **전투** = 전투 중에만, **둘 다** = 아무 때나.
- 획득: 결산 화면 25% 확률, 제갈량 각인, 사건, 보물 상점.

### 4.2 목록
| 계책 | 시점 | 효과 |
|---|---|---|
| 재점(再占) | 준비 | 방금 본 점괘를 향 소모 없이 다시 던짐 |
| 천기누설 | 준비 | 남은 장수 풀 수량 공개 + 다음 점괘 괘상 미리 보기 |
| 점성술 | 준비 | 다음 점괘 1회 흉·대흉 제외 |
| 차시(借屍) | 준비 | 판매한 장수 1명을 같은 값에 되사기 |
| 연환계 | 전투 | 적 무리 하나를 4초 묶음 (이동 정지) |
| 화계(火計) | 전투 | 로 1개에 5초 화염 지대 |
| 매복 | 전투 | 로 1개의 적 2초 기절 |
| 수공(水攻) | 전투 | 로 1개의 적을 2칸 뒤로 밀어냄 |
| 반간계 | 전투 | 적 1명이 3초간 아군 편에서 싸움 (보스 제외) |
| 금선탈각 | 전투 | 전사 직후 3초 안에 사용하면 그 장수를 체력 50%로 되살림 (영구 소멸 규칙의 유일한 되돌리기) |
| 공성계 | 둘 다 | 이번 웨이브 성 피해 0 (시련 판돈 보상은 받지 못함) |
| 고육책 | 둘 다 | 성 내구도 -10, 금 +8 |
