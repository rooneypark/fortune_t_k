# 레퍼런스 비교 v2 — 슬롯바운드 · 참고 게임 · 운빨삼국

- 작성: 2026-11-21. 프로토타입 1을 해 본 뒤 "완성도가 떨어진다, 전투가 슬롯바운드와 다르다"는 피드백으로 다시 조사했다.
- 슬롯바운드 출처: 팬 위키(slotbound-wiki.wiki, slotbounds.wiki), 데모 리뷰(todaywegame.gg), 게임메카 기사, Steam 상점. **위키는 추정이 섞여 있어** 수치는 확정이 아니다. 직접 플레이로 다시 확인할 것.
- 참고 게임: 전투 흐름(성벽 앞 측면 들판 전투) 구조만 참고했다. 그림·명칭·수치는 쓰지 않는다.

## 1. 세 게임의 전투 구조

| | 슬롯바운드 | 참고 게임 | 운빨삼국 v0.4 (프로토 1) | **운빨삼국 v0.5** |
|---|---|---|---|---|
| 배치 | 칸 없이 자리를 잡아 배치. "탱커 앞, 원거리 뒤" | 병사·장수가 성벽 앞에서 출격 | 3로 × 4열 칸 | **아군 진영 어디든 자유 배치** |
| 이동 | 웨이브 시작 시 자동 전투, 유닛이 움직임 | 병사가 달려가 싸움(run 모션), 한 방향 그림 좌우 반전 | 제자리 고정 | **평면 자유 이동 + 앵커 귀환, 한 방향 그림 좌우 반전** |
| 적 진입 | 한쪽, 심판 웨이브는 양면 | 한쪽(세로 화면 위) | 오른쪽 3로 | **정면 3곳 + 심판 때 위·아래** |
| 패배 조건 | 목숨 6개, 새어 나가면 -1 | 성벽 HP | 성 내구도, 새어 나가면 즉시 감소 | **성벽이 공격받아 성 내구도 감소** |
| 유닛 사망 | 영구 소멸 | 장수 25~40초 뒤 부활 | 다음 웨이브 부활 | **즉시 영구 소멸 (결정)** |
| 뽑기 시점 | **웨이브 중에도 돌림, 돌릴수록 비쌈** | 병사 자동 재소환(14~30초) | 준비 단계만 | **전투 중 점괘 가능, 웨이브 안에서 +1금씩 상승** |
| 실시간 개입 | 스핀, 흡수 | 주공 스킬(60~90초 뒤 해금), 카드 선택 | 없음 | **점괘·흡수·추격 태세·군령·계책** |

## 3. 그대로 유지하는 운빨삼국 고유 요소
- 점괘 1·2·3괘(보는 값 + 데려오는 값), 괘상 길흉, 운 게이지, 괘 맞춤, 천명
- 고사 시너지(도원결의·오호대장군·적벽), 군주별 패시브
- 공용 장수 풀과 3명 합성 (TFT 계열 — 슬롯바운드에는 없음)

## 4. 프로토타입 1의 완성도 문제 (이번에는 고치지 않음, 프로토타입 2에서 반영)
| 문제 | 원인 | 프로토 2 방향 |
|---|---|---|
| 전투가 정적이다 | 고정 포대 + 레인 | 필드 전투(§1) |
| 보는 재미가 약하다 | 사망·피격 연출, 투사체 종류 부족 | 피격 넉백·흰 번쩍임·사망 연출, 기술 범위 형태 7종 |
| 그림이 작고 단조롭다 | 코드로 그린 임시 인물 | 참고 게임 시트를 임시로 연결해 크기·밀도를 먼저 맞춰 보고, 최종은 새로 제작 |
| 결정할 게 적다 | 전투 중 할 일 없음 | 전투 중 점괘·추격 태세·흡수 |
| 성장 체감이 약하다 | 흡수 3단계뿐 | 레벨 30 + 전직 + 호위병 |
