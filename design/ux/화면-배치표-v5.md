# 화면 배치표 v5 (부록)

- 모든 화면의 요소 좌표. 단위 논리 px(1024 × 1792). 출처: 옛 카툰 시안에서 잰 `layout-v4.json`(배치만 유효, 그림체는 화면 설계서 §2를 따른다).
- 로비·전투는 화면 설계서 §4가 우선한다(v5 시안 기준).
- `종류`: btn 버튼, panel 판, plate 나무·진한 판, ribbon 제목 리본, chip 재화 칩, tabs 상단 탭, tabbar 하단 탭, card 장수 카드, slot 아이템·슬롯 칸, icon 아이콘, text 글자, bar 진행 바, badge 원형 배지, slider·seg·toggle 설정 조작, img 그림 자리, popup 팝업 본체, dim 어둡게 깔기.
- `기획만` 표시는 시안에 없고 기획에서 추가한 요소.
