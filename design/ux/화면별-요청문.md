# 화면별 그림 요청문 (제미나이)

2026-11-25 정리. 지금 쓰는 방식만 남겼다 (옛 방식 — 화면마다 완성 화면 + 마젠타 UI + 배경 세 장, 공용 부품 따로 받기 — 은 지웠다. 필요하면 git 기록에 있다).

## 방식

1. 화면마다 **완성 화면 한 장**을 세로(9:16, 1024 x 1792)로 받는다. 배경만 · UI만 그림은 받지 않는다.
2. 그림체 기준으로 이미 받은 완성 화면을 첨부한다 (로비 `로비8_완성화면.png`, 전투 `전투7_완성화면.png`). 캐릭터 비율은 `기준_캐릭터.png`.
3. 글자 · 숫자는 그리지 않게 하고, 아이콘은 첫 그림부터 전부 그리게 한다. 창 안의 버튼에는 글자 띠를 넣지 않는다.
4. 받은 그림은 `design/art/ui_src/`에 넣는다. Claude가 그 그림에서 부품을 직접 떼어 낸다:
   `tools/import_lobby4_ui.py` → `import_battle7_ui.py` → `import_popups8_ui.py` → `import_kit8_ui.py` → `import_icons8_ui.py`.
5. 화면 배치는 시안에서 잰 좌표 그대로 코드에 적는다. 창 없이 확인: `tools/layout_dump.tscn` → `python tools/layout_preview.py`.

받은 것 (모두 적용 끝): 로비 · 전투 · 난이도 · 흡수 · 웨이브 승리 · 결과 · 장수 목록 · 장수 상세 · 가방 · 장비 상세 · 합성 · 상점 · 구매 확인 · 우편 · 임무 · 주공 정보 · 설정 · 보상 · 인트로.
