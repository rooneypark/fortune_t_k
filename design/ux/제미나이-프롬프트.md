## 0-3. 내일 할 순서 (2026-11-24 아침, 지금 초안 기준) — 이것부터

지금 게임 로비 = **배경 한 장(가운데 성문 하나) + 위 HUD(초상 · 금 · 군량 · 설정 · 우편 · 임무) + 하단 탭(출정 · 쟁패 · 장수 · 가방)**.

## 0-2. 다시 잡은 순서 (2026-11-23 저녁, 로비 구조 변경 뒤) — 이것부터

## 1. 공통 그림체 (대화 맨 처음에 한 번)

```
지금부터 세로형 모바일 게임 "운빨삼국"의 UI 그림을 여러 장 부탁할게. 모든 그림에 아래 규칙을 지켜 줘.

[게임] 삼국지 소재의 2D 도트(픽셀 아트) 오토 디펜스. 화면 왼쪽 성벽을 지키고 오른쪽에서 적이 온다. 슬롯머신으로 병사와 장수를 뽑아 세운다.
[그림체] 캐슬바운드(Castlebound) 같은 2D 도트 오토 디펜스 장르의 느낌: 큼직하고 또렷한 도트, 밝고 선명한 색, 굵은 검은 외곽선, 한눈에 읽히는 모양.

[도트 규칙] 진짜 픽셀 아트처럼: 큰 정사각형 도트, 안티에일리어싱·흐림·그라데이션 없음, 색 수는 적게(그림당 16색 안팎).

[배경] "누끼"라고 한 그림은 배경을 완전한 마젠타 단색(#FF00FF)으로 칠해 줘 (그림자·안개 없이). 그림 안에는 마젠타를 쓰지 마.
알겠으면 "준비됐어"라고만 답해 줘.
```
