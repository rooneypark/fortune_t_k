## 2. 스타일 가이드

### 2.1 그림체
- 밝은 낮의 **픽셀아트**. 큰 픽셀(시안 기준 약 4px = 원본 1픽셀). 부드러운 그라데이션·블러·광택 없음.
- 캐릭터: 작은 2~3등신 픽셀 병사·장수. 세력은 옷·깃발 색으로만 구분.
- 공통 UI에는 세력 글자(魏·蜀·吳)를 쓰지 않는다. 깃발은 금색 구름 문양.

## 3. 화면 지도

```
[로비] ──팻말──> [스테이지 선택] ──출정──> [전투] ⇄ (일시정지·설정)
  │                                         ├─ 웨이브 승리 → 다음 웨이브
  │                                         ├─ 보스 경고
  │                                         └─ 결과(승리 / 패배·이어하기) → 로비 / 다시 출정
  ├ 왼쪽: 우편 · 임무 · 패스      ├ 위: 주공 초상 → 주공 정보 · 톱니 → 설정 · 재화 + → 상점
  └ 하단 탭: 장수 → 장수 상세(강화·성급·보물) / 편성 / 군웅대전 / 모집 → 결과·확률 / 상점
```

- 하단 탭(장수·편성·군웅대전·모집·상점)은 로비와 탭 화면 5개에서 늘 보인다. 상세·팝업·전투에서는 숨긴다.
- 뒤로: 화면 왼쪽 위 뒤로 버튼 또는 기기 뒤로 키. 로비에서 뒤로 = 종료 확인 창.

## 6. 연출 기준
- 모든 연출은 화면을 누르면 건너뛴다. 기본 1초 이내, 대박만 1.5초.
- 릴: 0.35초 간격으로 왼쪽부터 멈춤. 당첨 칸 금색 깜빡임 2회.
- 영입 등장: 0.25초 "펑"(세로로 늘었다 돌아옴). 등급업: 금색 빛 기둥 + 금 띠 추가.
- 성 피격: 성 체력 바 흔들림 + 빨간 번쩍임. 성 30% 이하: 바 깜빡임.
- 화면 흔들림은 설정에서 끌 수 있다.

## 7. 구현 순서 (권장)
1. 전투 개정: 자유 배치, 대기석 8칸, 끌어서 흡수, 특성 선택 팝업 (규칙 GDD §3.3~3.4b)
2. 스테이지 선택 + 결과(승리·패배) + 웨이브 승리·보스·일시정지 팝업 픽셀화
3. 장수 목록 → 장수 상세 3탭 → 편성
4. 모집(+결과·확률) → 보물 가방·상세
5. 상점 → 임무·출석 → 패스 → 우편 → 주공 정보 → 설정
6. 계정·세이브·서버(결제 검증, 모집 결과 서버 결정) → 군웅대전
- 각 단계마다 시안(또는 배치표)과 실제 화면 스크린샷을 나란히 비교한다.
