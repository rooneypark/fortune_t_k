# 운빨삼국 — 제미나이 UI 그림 의뢰서 (2026-11-23)

- 이 문서와 **영역 지도**(`design/ux/규격/zones/*.png`)를 같이 넘긴다. 지도의 상자 하나가 그림 파일 하나다.
- 게임에는 지금 **같은 이름의 임시 그림**이 들어 있다. 새 그림을 같은 이름 · 같은 크기로 저장해서 덮어쓰면 코드를 고치지 않아도 바로 바뀐다.
- 자세한 크기 표와 아이콘 목록: `design/ux/UI-그림-규격.md`. 색 · 판 스타일: `design/ux/UI-테마-기획서.md` §1~§3.

---

## 1. 어떤 게임인가 (그림체)

| 항목 | 내용 |
|---|---|
| 장르 | **2D 도트(픽셀) 오토 디펜스.** 왼쪽 성벽을 지키고, 오른쪽에서 적이 온다. 슬롯으로 병사 · 장수를 뽑아 세운다 |
| 소재 | 삼국지 (장수 32명, 병종 16종) |
| 느낌 | 캐슬바운드(Castlebound) 같은 **2D 도트 오토 디펜스 장르의 느낌**: 큼직한 도트, 밝고 선명한 색, 굵은 검은 외곽선, 한눈에 읽히는 아이콘 |
| **꼭 지킬 것** | 장르의 느낌만 참고한다. **그 게임의 그림 · 캐릭터 · 로고 · UI 모양을 베끼거나 닮게 만들지 않는다.** 모든 그림은 새로 그린 독자 그림이어야 한다 |
| UI 판 | 짙은 남색 판 + 얇고 밝은 테두리 (테마 기획서 §1). 나무결 · 리벳 · 금박 장식은 쓰지 않는다 |

## 2. 기술 규격 (모든 그림 공통)

| 항목 | 값 |
|---|---|
| 화면 | 세로 **1024 × 1792 px** = **256 × 448 도트** (도트 1칸 = 4px) |
| 그리는 법 | 도트 크기로 그린 뒤 **4배 최근접(nearest)으로 키워 저장**. 흐림 · 안티에일리어싱 없음 |
| 파일 | PNG. 누끼(투명 배경) 부품은 바깥이 완전히 투명 |
| 글자 | **그림에 글자를 넣지 않는다.** 숫자 · 이름은 게임이 쓴다 (숫자 자리는 비워 둔다) |
| 크기 | 아래 표의 크기 그대로. 4의 배수 |
| 9-slice 판 · 버튼 | 늘어나는 부품. 모서리 4도트(16px), 테두리 1도트(4px) 안에만 장식 |
| 버튼 눌림 | 통째 그림 버튼은 `이름_pressed.png`도 하나 (없으면 게임이 어둡게 처리) |

## 5. 넘기는 법 · 받는 법

1. 제미나이에게: 이 문서 + `zones/` 지도 PNG(필요한 화면) + 지금 임시 그림(`assets/ui/…`)을 준다.
2. 받은 그림을 **같은 경로 · 같은 이름**으로 저장한다.
3. `godot --headless --path . --import` 후 게임을 켜서 본다. 크기가 다르면 화면에서 늘어나 보이니 크기부터 확인한다.
4. 임시 그림을 다시 만들려면 `python tools/draw_ui_placeholders.py` (정식 그림을 덮어쓰니 주의).

## 7. 다시 만드는 법

| 할 일 | 명령 |
|---|---|
| 임시 그림 | `python tools/draw_ui_placeholders.py` |
| 자리 측정 (창 없음) | `godot --headless --path . --audio-driver Dummy --resolution 1024x1792 res://tools/layout_dump.tscn -- --no-save --save=<임시 json>` |
| 영역 지도 | `python tools/zone_maps.py` → `design/ux/규격/zones/` |
| 실측표 | `python tools/ui_spec.py` → `design/ux/규격/측정표.md` |

- 로비 지도에는 들어갈 때 뜨는 출석 보상 창이 겹쳐 그려져 있다 (가운데 800 × 700 판, "확인" 버튼). 로비 자체 부품이 아니다.
- 예전 배경 그림(로비 · 인트로 · 메뉴 · 전장)은 `design/art/old_bg/`에 보관했다.
